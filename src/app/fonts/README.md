# Self-hosted fonts

- **Archivo** (display) — SIL Open Font License 1.1
- **IBM Plex Sans / IBM Plex Mono** (body / utility) — SIL Open Font License 1.1

Both licenses permit embedding and self-hosting. Files are Latin subsets loaded
via `next/font/local` in `src/app/layout.tsx`. To swap the brand typography for a
client, replace these files (and the weights referenced in `layout.tsx`).
