# /public — static assets

Put images and static files here; they're served from the site root
(`/public/work/tint-shop.jpg` → `https://your-site.com/work/tint-shop.jpg`).

## What to add
- `favicon.ico` — optional. A favicon is already generated by `app/icon.tsx`;
  drop a real `favicon.ico` here to override it.
- `og.jpg` (1200×630) — optional. A social image is generated by
  `app/opengraph-image.tsx`; add real art here and point `openGraph.images` at it
  if you prefer a designed image.
- `work/` — project screenshots. Reference them from
  `src/content/portfolio.ts` via the `image` field (e.g. `/work/tint-shop.jpg`).
- Hero and About photos — reference from the respective components/config.

## Tips
- Use web-friendly formats (WebP/AVIF/optimized JPG/PNG).
- Always provide descriptive `alt` text (the components require it).
- `next/image` handles sizing/optimization automatically.
